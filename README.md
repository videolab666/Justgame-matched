# Не ведись!

Браузерна гра «три в ряд» про шахрайство (4 розділи, 24 рівні): збирай однакові речі, гаси фейки, а коли
приходить повідомлення — вирішуй за 6 секунд, фейк це чи справжнє.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # логіка й контент (Vitest)
npm run bot      # баланс: бот грає кожен рівень 30 разів
npm run build    # статична збірка в dist/ (PWA: manifest + service worker)
npm run preview  # перевірити збірку локально, у т.ч. офлайн
```

## Структура

- `src/logic/` — чиста детермінована логіка (поле, збіги, каскади, спецплитки, фейки, рівень). Без DOM і Pixi, покрита тестами.
- `src/content/` — 24 рівні в 4 розділах (Банк, Маркетплейс, Родина, Держпослуги й соцмережі) і 64 сценарії повідомлень (`scams.ts`), колода без повторів.
- `src/render/` — PixiJS-поле: текстури з SVG, свайп, програвання кроків логіки через GSAP.
- `src/fx/` — частинки, промені, ударна хвиля, блискавки, глітч, тряска, slow-mo, авто-якість.
- `src/audio/sfx.ts` — синтезовані звуки (WebAudio), без аудіофайлів.
- `src/ui/` — HUD, картка повідомлення, екрани (старт, карта, результат з розбором, налаштування).
- `docs/superpowers/` — дизайн і план реалізації.

## Ліцензії

Уся графіка (плитки, фейки, пес Чек) і тексти — власні.

## Механіки за розділами

1. **Банк** — фейк-SMS, 2FA (4 в ряд), «Сповіщення» (Г/Т з п’яти).
2. **Маркетплейс** — фейк-оголошення в рамці: два удари.
3. **Родина** — фейк-дзвінок щоходу перескакує; КЕП (5 в лінію) прибирає всі речі одного виду.
4. **Держпослуги й соцмережі** — підробка маскується під звичайну річ (збіг поруч зриває маску); обмін двох спецплиток — супер-комбо.

## Справа дня

60-секундний раунд на одному для всіх полі (сід — дата). Верна відповідь «Справжнє» дає +5 секунд, «Фейк» — Кіберполіцію.
Рекорд дня, серія днів поспіль і картка результату для «Поділитися» (системне меню телефону або копіювання в буфер).

## PWA

`public/manifest.webmanifest`, іконки з псом Чеком, `public/sw.js`: оболонка кешується при встановленні, решта (асети, шрифти) — під час першого використання. Service worker реєструється лише у production-збірці.
